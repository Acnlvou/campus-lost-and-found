# 校园失物招领系统

本仓库为校园失物招领系统的空白项目骨架，依据课程作业交付要求整理过程文档目录，并参考 AgriNet 项目的 backend、deploy、desktop、docs、scripts 分层。当前只放置目录说明 Markdown，不包含应用代码或其他实现文件。

## 当前需求范围

课程需求基线描述了演示账户登录、失物/招领信息发布、组合检索、认领申请、发布者审核和并发一致性控制。图片上传、站内通知、校园真实身份认证和后台管理属于后续范围；实现范围以最终评审通过的 SRS 基线为准。

## 目录

- `.vscode`：编辑器工作区配置。
- `backend`：服务端接口、业务模块、数据访问、配置和测试。
- `deploy`：部署与平台原生资源。
- `desktop`：客户端界面及桌面端外壳相关代码目录，技术方案确定后再落入实现。
- `docs`：项目开发文档和课程作业交付物。
- `scripts`：开发、数据维护和打包辅助脚本。

每个文件夹中的 `README.md` 说明该目录的用途。后续新增代码或材料时放入对应目录，并在涉及需求、测试和版本变化时同步更新过程资产与证据。
