## . 基于改进指南的修改记录

## . 1 禁止本人认领（高优先级）

- **目标**：满足 REQ-004 规范，禁止用户认领自己发布的招领信息
- **改动内容**：修改配置项 `ALLOW_SELF_CLAIM = False`，开启自动迁移函数，
- **涉及文件**：`campus/__init__.py`
- **实现结果**：物品发布者看不到认领按钮；

## 3. 发布新增待审核提示（中优先级）

- **目标**：发布成功后给出文字提醒，避免用户误以为提交失败
- **改动内容**：在 publish 接口添加 flash 提示；在 base.html 中增加消息渲染代码
- **涉及文件**：`campus/__init__.py`、`campus/templates/base.html`
- **实现结果**：提交发布后，页面顶部弹出 “信息已提交，等待管理员审核” 提示
